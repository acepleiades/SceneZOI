# Neutral sofa hub source clips

`HZoi_sofa_idle_F.fbx` and `HZoi_sofa_idle_M.fbx` are the original body-animation
sources for SceneZOI's neutral sofa hub. aceanimations / acepleiades grants these
two clips under the repository's [GPL-3.0-only license](../../LICENSE), including
the identical body clips used by HZoi. Both run for four seconds at 60 FPS.

These files contain animation and skeleton data. They do not include the game
body meshes or a male genitals track. Other HZoi animations and third-party assets
retain their separate licenses.

The [import plan](../../imports.json) gives their framework asset paths.
The [sofa guide](../../docs/furniture.md#sofa-authoring-and-placement) explains the
44 cm authoring surface and placement between two sitting spots.
