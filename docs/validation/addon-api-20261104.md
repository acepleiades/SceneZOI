# Add-on API/SDK findings — 2026-11-04

Runtime `20261104-api-5`, public API version 1. Validation used an independent
native add-on with creator and observer SDK clients, not private framework calls.
The final cold-start run passed 95 assertions/checked responses; earlier runs
included up to 98 because polling counts vary. These are not 98 distinct features.

## Verified

- Explicit-role search/preflight, inert scene/role/action data, ordinary navigation
  and restrictions, permission refusals, independent speed/task controls, competing
  completion holds and real task events, caller-scoped effects, expiry and results.
- Actual native prop creation/readiness/removal, unavailable-asset failure and
  normal cleanup; supported bed discovery/entry/release.
- A manually started voiced session accepted a late observer, independent native
  mutes/unmute and orderly observer Exit. Fourteen real seconds paused preserved
  renewal while task completion/playing time stayed frozen. Saved preferences matched.
- Muted clothing re-entry did not restart a native clip after the fix. Outsider
  possession preserved observer access, and a loaded expression override had no error.
- A B2 SDK surviving B1 host reload observed instance change, rejected obsolete
  host state/registration, and subscribed/registered again using fresh owner wrappers.
- A ModKit-created, packaged native project loaded its SDK and both declaration
  rows automatically after process restart, without manual mount/data patching.
- Controlled identity, settings, all four collision/autonomy states and tested bed
  occupancy matched baseline. Framework/HZoi payloads and user preferences were preserved.

## Failures and fixes

| Finding | Resolution |
| --- | --- |
| Muted playback briefly restarted during outfit re-entry. | Skip entering a muted continuous voice engine. Retain the actual-engine regression. |
| Intentionally muted completion responses logged an unavailable-response warning. | Suppression is not an asset failure; keep genuine missing-asset diagnostics. |
| Native owner references became stale across partial environment reload. | SDK `refresh_owner` / optional owner argument to `tick`, scoped to the same entity ID. |
| Global and bound callbacks advanced the developer clock twice. | One real-time driver per client. |
| Retained terminal diagnostics were mistaken for a new run. | Correlated run/request/session IDs and readiness readback. |
| A catalog mesh could not load in retail. | Use an actually installed compatible asset; the failed request exited cleanly. |
| An unregistered Lua scaffold/export did not auto-load scripts/declarations. | Create the native project through ModKit, preserve generated metadata/protection and verify a fresh-process installation. |
| The filter assumed every mod had cooked assets; the native zero-asset hash file was empty. | Exact Lua/data-only allowlist and five rejection/validity regressions. |
